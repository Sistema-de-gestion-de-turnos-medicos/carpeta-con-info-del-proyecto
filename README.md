# carpeta-con-info-del-proyecto

Sistema de gestión de turnos medicos

Defición del negocio

Título del Proyecto:  Sistema de Gestión de Turnos Médicos

Descripción del problema:

En muchos centros médicos, la gestión de turnos se realiza de forma manual o con sistemas poco integrados, lo que genera problemas como sobre-reservas, largas esperas, pérdida de información y mala experiencia para el paciente.

Solución propuesta:

MediTurn es una plataforma basada en microservicios que permite a pacientes reservar, modificar y cancelar turnos médicos de forma online, mientras que los profesionales de la salud pueden gestionar su disponibilidad y agenda en tiempo real.

Arquitectura de microservicios

El sistema estará dividido en los siguientes microservicios:

1.Servicio de Usuarios
2.Servicio de Autenticación
3.Servicio de Pacientes
4.Servicio de Médicos
5.Servicio de Especialidades
6.Servicio de Turnos
7.Servicio de Disponibilidad
8.Servicio de Notificaciones
9.Servicio de Pagos
10.Servicio de Historial Médico
